# План разработки

0. Подготовка — выполнены диагностика, структура, окружение и тестовый запуск.
1. Ollama — сначала проверить соединение и получить список моделей (1.1), затем создать GUI и добавить потоковые ответы, отмену и историю.
2. OpenAI — общий интерфейс провайдеров, клиент Responses API, выбор провайдера и хранение ключей.
3. Голосовой ввод — микрофон, VAD, распознавание и активация.
4. Голосовой вывод — Piper, подготовка записей, сравнение голосов и резервный движок.
5. Личность и память — профиль характера, история SQLite, долговременная память.
6. Инструменты — разрешения, Windows, документы, цепочки действий.
7. Персонаж — окно поверх приложений, анимации и синхронизация с голосом.
8. Завершение — голосовой UX, оптимизация, сквозные проверки и установщик.
