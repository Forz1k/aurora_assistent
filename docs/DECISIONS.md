# Решения

- Используем Python 3.11 x64 в локальной .venv. При старте модели не загружаются.
- Настройки хранятся в YAML. Сейчас поддерживается log_level со значениями DEBUG, INFO, WARNING, ERROR и CRITICAL. По умолчанию INFO.
- Локальный журнал исключён из Git. Ротация при 1 МиБ сохраняет до трёх архивных файлов.
- PyYAML нужен приложению, pytest установлен как зависимость разработки. Версии прямых зависимостей закреплены в requirements*.txt.
