## Задача 3.2 выполнена

## Задача 3.3 выполнена

Режим --listen ожидает имя отдельной репликой, после паузы приглашает произнести одну команду и выводит её текст. Используются текущие настройки микрофона и --seconds. Решение: Silero VAD выделяет реплики, существующая модель faster-whisper base проверяет имя на CPU. Модель переиспользуется в течение процесса. Зависимости не добавлялись.

Добавлены aurora/audio/wake.py и tests/test_wake.py. Обновлены aurora/audio/input.py, aurora/audio/stt.py, aurora/__main__.py, README и этот файл. 23 теста прошли. Проверка на синтезированной русской речи через настоящий VAD и STT: «Добрый вечер» не активировало запись, «Аврора» активировала, следующая команда распознана как «Открой документ». Точность на живом голосе через fifine не измерялась.

Исправление 3.3 после проверки на fifine: прежняя версия повторяла приглашение и переоткрывала вход после каждой несовпавшей расшифровки. Теперь отдельный потоковый детектор Vosk слушает один открытый вход до совпадения, приглашение печатается один раз. Whisper используется для команды. Установлены vosk 0.3.45 и русская модель vosk-model-small-ru-0.22 в data. Изменены wake.py, tests/test_wake.py, requirements.txt, README.md и этот файл.

Проверки: вход 2 передал детектору 64 блока; синтезированное имя распознано при трёх темпах, две посторонние фразы отклонены. 26 тестов прошли, pip check успешен. Активация голосом пользователя ещё не подтверждена.
