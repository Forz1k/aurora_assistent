# Архитектура

Точка входа python -m aurora читает config/settings.yaml через safe_load, проверяет log_level и открывает logs/aurora.log в UTF-8. Оба пути по умолчанию отсчитываются от корня проекта. Ошибка чтения конфигурации или открытия журнала выводится в stderr и завершает процесс с кодом 1.

Подготовленные пакеты для следующих этапов:

- core — события, состояния и координация.
- providers — клиенты Ollama и OpenAI.
- audio и tts — голосовой ввод и синтез.
- personality и memory — характер, история и контекст.
- skills, documents и security — действия, обработка документов и разрешения.
- ui — чат, настройки и персонаж.

В чате Qt асинхронно читает строки NDJSON из POST /api/chat. Остановка вызывает abort у активного сетевого запроса. После признака done и успешного завершения HTTP одна транзакция SQLite сохраняет вопрос и ответ в data/chat.sqlite3. Окно загружает сохранённую беседу при открытии.

На этапе 2.1 введён LLMProvider. Метод list_models вызывается в рабочем потоке окна, а stream(model, messages) возвращает объект ChatStream для цикла событий Qt. Сигнал chunk передаёт текст, finished завершает запрос и сообщает об ошибке либо отмене. Кнопка остановки вызывает cancel. OllamaProvider отвечает за HTTP и разбор NDJSON. ChatWindow принимает провайдер через именованный аргумент provider и управляет отображением и историей.

OpenAIProvider реализует LLMProvider через поток событий Responses API. Конструктор принимает API-ключ и имя текстовой модели, list_models возвращает настроенное имя. Клиент передаёт сообщения в input с параметром store=false. Ключ используется в заголовке Authorization. Выбор провайдера и подключение хранилища секретов запланированы на 2.3.
