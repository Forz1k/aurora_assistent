# Проверки

Из корня проекта запустить .\.venv\Scripts\python -m pytest -q. Пять сценариев проверяют точку входа с корректными настройками, неизвестным уровнем, ошибкой синтаксиса YAML, неверной структурой и отсутствующим файлом. Для ошибочных настроек проверяется код 1 и сообщение в stderr.

Ручная проверка: запустить .\.venv\Scripts\python -m aurora с исходным конфигом, затем Get-Content logs/aurora.log -Encoding utf8 -Tail 1. Ожидается запись уровня INFO о завершении тестового запуска.

Проверка этапа 1.3 входит в pytest. Локальный тестовый HTTP-сервер выдаёт частичный ответ, ждёт отмены, имитирует обрыв и возвращает завершённый ответ при повторе. Тест открывает окно заново и проверяет восстановленный контекст следующего запроса. База истории создаётся во временном каталоге.

## 4.3 · Сравнение русских голосов на Xeon E5-2690 v3

Фраза «Аврора на связи. Проверка микрофона завершена.». У Qwen использован фрагмент 0280 (3,34 с), PyTorch 2.6.0+cpu, float32, 8 потоков, seed 42, без обучения. Каждый запуск шёл в отдельном процессе. Время загрузки включает импорт библиотек, синтез включает подготовку референса и запись WAV. Память — пиковый рабочий набор процесса Windows. Вычисления на CPU, расход VRAM отдельно не измерялся.

| Вариант | Загрузка, с | Синтез, с | Аудио, с | RTF | Пик RAM, МиБ |
|---|---:|---:|---:|---:|---:|
| Piper, Ирина | 2,21 | 0,37 | 4,09 | 0,092 | 191,5 |
| Qwen, аудио и расшифровка | 33,78 | 57,44 | 3,36 | 17,09 | 5654,3 |
| Тот же Qwen, повтор из нового процесса | 20,78 | 34,70 | 3,36 | 10,33 | 5653,1 |
| Qwen, только голосовой вектор | 20,68 | 39,11 | 4,24 | 9,23 | 5653,8 |

Whisper base распознал все слова в обоих вариантах Qwen. В образце Piper имя записано как «А врура». Это проверка разборчивости распознавателем, субъективное качество произношения оценивается прослушиванием.

Косинусное сходство с векторами двух отдельных исходных фрагментов 0198 и 0310, извлечёнными энкодером Qwen: Piper 0,938/0,949, Qwen с расшифровкой 0,974/0,981, Qwen по вектору 0,976/0,980. Энкодер связан с тестируемой моделью. Близкие результаты двух режимов на одной фразе не определяют предпочтительный тембр.

Для живого диалога по задержке подходит Piper. Qwen подходит для предварительного синтеза и кеширования. Образцы и страница локального прослушивания находятся в data/voice-studio/comparison.
