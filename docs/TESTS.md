# Проверки

Из корня проекта запустить .\.venv\Scripts\python -m pytest -q. Пять сценариев проверяют точку входа с корректными настройками, неизвестным уровнем, ошибкой синтаксиса YAML, неверной структурой и отсутствующим файлом. Для ошибочных настроек проверяется код 1 и сообщение в stderr.

Ручная проверка: запустить .\.venv\Scripts\python -m aurora с исходным конфигом, затем Get-Content logs/aurora.log -Encoding utf8 -Tail 1. Ожидается запись уровня INFO о завершении тестового запуска.

Проверка этапа 1.3 входит в pytest. Локальный тестовый HTTP-сервер выдаёт частичный ответ, ждёт отмены, имитирует обрыв и возвращает завершённый ответ при повторе. Тест открывает окно заново и проверяет восстановленный контекст следующего запроса. База истории создаётся во временном каталоге.
